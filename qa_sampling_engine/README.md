# QA Sampling Engine

This project demonstrates a simplified QA sampling workflow.

## Purpose

The goal is to select QA review samples from a larger pool of reviewed materials.

The workflow supports:

- Duplicate material prevention
- Fixed-count sampling
- Percentage-based sampling
- Reviewer-level sampling

## Key Concepts

- Random sampling
- Material ID deduplication
- Reviewer-level grouping
- QA audit sample selection

## How To Run

```bash
python sampler.py
