# Data Dictionary

| Field | Description |
|---|---|
| `material_id` | Mock review item identifier |
| `operator_id` | Mock operator or reviewer identifier |
| `review_date` | Date when the review was completed |
| `system_description` | Description generated by the system or model |
| `reviewer_description` | Manual reviewer feedback or finding |
| `review_status` | Readable status such as `published`, `rejected`, or `unknown` |
| `status_code` | Raw status code from the JSON payload |
| `entity_type` | Type of reviewed entity, such as product, creator, or video |
| `subject_category` | Review reason or category from the reviewer result |
| `confidence_score` | Mock model/system confidence score |
| `language` | Review language from metadata |
| `region` | Mock region from metadata |
| `source` | Mock source system |
| `description_too_short` | Flag for system descriptions under 30 characters |
| `missing_subject_category` | Flag for missing subject category |
| `low_confidence` | Flag for confidence below 0.70 |
| `is_rejected` | Boolean flag for rejected cases |
